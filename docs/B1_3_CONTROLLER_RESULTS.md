# B1.3 可训练控制器：首轮训练与留出评估

日期：2026-11-09。[实验协议](B1_3_CONTROLLER_PROTOCOL.md)在训练/测试前记录；模型选择与测试分别执行。当前文件记录首轮有限预算实验，不代表完整研究方向的最终结论。

**结论：真实可训练控制器已实现并完成测试，但主指标没有超过调优后的强基线。MLP 在 ID 宏平均上低于 HazardFilter 约 0.12 个百分点；GRU 在部分变化场景有局部优势，同时表现出噪声鲁棒性的代价。**

## 1. 训练和验证已经完成

- MLP：146 参数，三个初始化；GRU：402 参数，三个初始化。
- 每次训练 12 epoch，400 条训练 episode，完整 300 轮 BPTT。
- 200 条验证 episode 用于选择 epoch 和基线参数；没有读取测试数据来调参。
- 全部模型实际发生参数变化，不是将手工规则命名为神经网络。
- CPU 单线程，总 fit 时间约 364 秒；单次 MLP 约 47 秒，GRU 约 61 秒。这是本机运行时间，不是硬件标准化性能测试。

独立从保存的训练/验证轨迹重跑了 MLP@17 的全部 12 epoch：选中 epoch、验证指标和 checkpoint 中的每个参数张量均与首次运行完全一致。这验证了一次完整训练复现，不代表六个初始化均已重跑。

## 2. 验证阶段的门控诊断

仅统计存在有效报告的槽，按报告是否与已有硬预测一致分组。以下是验证数据，不是测试结果，也不是噪声/漂移识别准确率。

| 控制器初始化 | 一致报告的平均写入门 | 冲突报告的平均写入门 |
| --- | ---: | ---: |
| MLP 17 | 0.5486 | 0.3810 |
| MLP 29 | 0.5169 | 0.3596 |
| MLP 43 | 0.4826 | 0.4088 |
| GRU 17 | 0.3757 | 0.4151 |
| GRU 29 | 0.3924 | 0.4109 |
| GRU 43 | 0.3705 | 0.4091 |

MLP 学到了对冲突报告更保守的平均更新行为；GRU 的平均模式不同。**不能据此断言网络理解了“错误反馈”或“真实漂移”**：一致/冲突不是正确/错误，两组还混合了不同置信度、证据年龄和场景。遗忘门整体较小，是否有益需要留出消融检验。

## 3. 留出测试

本轮锁定 20 个测试数据种子、每场景 10 个用户、300 轮，五个 ID 与三个 OOD 场景，共 1,600 条 episode、480,000 个环境轮次。所有方法共享轨迹，测试后不再调整训练。

独立 test 命令已完成，运行时间约 597 秒。没有根据测试成绩改模型、选 epoch、挑训练初始化或重选主参考基线。

### 主结果

以下为三次训练初始化的指标均值，不是预测集成；基线为验证集选定的一套全局配置。单位：百分比，越高越好。

| 场景 | HazardFilter | MLP | GRU |
| --- | ---: | ---: | ---: |
| **ID 宏平均（主端点）** | **94.79** | 94.66 | 94.57 |
| 静态干净 | 97.48 | 97.48 | 97.48 |
| 稀疏噪声+突变 | 87.69 | 87.43 | 86.99 |
| A→B→A | 93.75 | 93.86 | **94.29** |
| 临时需求，范围可见 | **98.03** | 97.97 | 97.91 |
| 临时需求，范围不可见 | **96.97** | 96.58 | 96.20 |
| OOD：35% 噪声 | **75.28** | 74.56 | 73.66 |
| OOD：10% 报告率 | **75.94** | 75.63 | 75.89 |
| OOD：随机局部多维变化 | 85.60 | 85.33 | **86.03** |

表中加粗仅比较这三列，并非重新根据测试选冠军：例如高噪声 OOD 中，DiscountedCounts 为 75.86%，高于表内三者。所有基线、每次训练初始化与消融结果均在 [`summary.json`](../results/b1_3_controller_test/summary.json)。

主控制器 MLP 相对 HazardFilter 的 ID 宏平均准确率差：

**−0.1224 个百分点，95% 配对数据种子聚类 bootstrap CI：[−0.1667, −0.0807]。**

因此没有达到事先记录的“至少提升 1 个百分点且区间下界大于 0”的目标。六个单独训练运行的 ID 宏平均也都低于主参考基线，不能通过挑初始化得到整体胜出结论。

### 概率评分不支持单一的“全面更优”叙述

| ID 宏平均 | HazardFilter | MLP | GRU |
| --- | ---: | ---: | ---: |
| NLL（低为好） | 0.14471 | **0.14162** | 0.14798 |
| Brier（低为好） | **0.07446** | 0.07641 | 0.07962 |

MLP 的 NLL 较低，但硬准确率和 Brier 较差。不同适当评分规则可能给出不同排序；这不是已证明更好的概率校准，不能只选 NLL 宣布成功。

### GRU 的局部线索

相对已锁定的 HazardFilter：

- A→B→A：**+0.540 个百分点**，描述性 95% CI **[+0.478, +0.607]**。
- OOD 随机局部变化：**+0.435 个百分点**，CI **[+0.328, +0.546]**。
- OOD 35% 噪声：**−1.628 个百分点**，CI **[−1.914, −1.359]**。

随机局部变化中的持续恢复率，HazardFilter 为 73.81%，GRU 为 74.94%；但 GRU 的实际硬预测损伤率也更高（18.34% vs 14.56%），且其 NLL/Brier 在该场景仍较差。这与更积极的适应行为相符，但不足以证明已经解决稳定性—可塑性权衡。

GRU 不是验证阶段选出的主家族；这些属于次要/探索性结果。由于没有对 GRU 进行无历史状态的留出干预，也不能把局部优势因果归结为其短期记忆。

### 遗忘门干预：收益依赖场景

对验证阶段选定的 MLP 家族，将遗忘门设为 0，不重训。下表是**完整 MLP 减去 no_forget**的准确率差，单位为百分点：

| 场景 | 差值 | 描述性 95% CI |
| --- | ---: | --- |
| ID 宏平均 | +0.0137 | [+0.0033, +0.0235] |
| A→B→A | +0.2589 | [+0.2402, +0.2772] |
| 稀疏噪声 | −0.0613 | [−0.0893, −0.0343] |
| 临时需求，范围不可见 | −0.1013 | [−0.1211, −0.0824] |
| OOD 随机局部变化 | +0.2046 | [+0.1776, +0.2298] |

遗忘有助于追踪变化，却可能破坏抗噪稳定性。宏平均收益很小，远小于实际意义阈值；不能将统计可检测的微小差异解释为实质突破。这是固定已训练模型的推断干预，不等同重新训练无遗忘模型的消融。

## 4. 下一轮研究应回答的问题（尚未执行）

1. **训练预算是否限制了 GRU？** 三次最佳 epoch 均在末尾。可以在新实验设计中预先设定更长预算和停止规则，而不是看到测试后继续训练同一盲测。
2. **概率空间的凸组合是否是限制？** 下一轮可对照“固定 Bayes 滤波”“学习报告可靠度/变化率的 Bayes 更新”“当前概率平均门控”，定位收益来自表示还是控制策略。
3. **遗忘是否缺少噪声与变化的区分？** 分开控制环境变化率和报告噪声率，检验同样的预测冲突在两种原因下是否需要不同更新，而不是只增加网络容量。
4. **真实部署监督是否可得？** 另行研究只用未来可观测报告的目标；当前隐藏状态监督仍是机制实验的特权条件。

当前不据此扩展动态拓扑或 Hypernetwork。后续任何调整应重新锁定设计，并保留新的最终测试种子；当前测试已被使用，不能再次作为未见盲测。

## 5. 能力与证据边界

- 这是隐藏状态可监督的模拟器离线元训练，不是从真实用户稀疏反馈完成端到端训练。
- 在线更新的是个人信念/GRU 状态，控制器参数冻结；不是在线微调整个 LLM，也没有实现自主连接生长。
- MLP、GRU 分别需要 240 和 624 字节每用户张量状态，不含运行时开销，不能宣称与所有基线严格等内存。
- 三个 GRU 的最佳 epoch 都在预算末尾，可能尚未收敛。本轮预算下若不胜出，只能约束这组实现和训练设置，不能证明整个神经记忆方向无效。
- 测试区间按数据种子聚类，主结果平均三个训练初始化，但没有完整量化训练随机性的总体分布；也没有多重比较校正。
- 原始 NPZ 中的 gates 是模型提出的门值。缺失/本轮报告不应用这些门；`no_forget` 干预实际将遗忘设为 0，保存的提议门值不应被误读成已执行更新。
